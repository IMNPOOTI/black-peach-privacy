Privacy policy · 9 October 2026

01 / Privacy policy · effective 9 October 2026

Trivia scores. Minimal data.

Icon runs trivia questions inside Discord. You can choose a question category, answer using buttons and view daily or all-time leaderboards. The bot processes a limited amount of Discord account information to keep the game and its scores working.

Information collected and stored

  • Discord user ID: identifies the account that earned points and links those points to its all-time and daily scores.
  • Scores: the number of correct answers credited to each participating user, in both an all-time tally and a current daily tally identified by date.

The scores are written to a local JSON file (scores.json) on the bot operator's computer. The score file stores Discord IDs and numerical totals, not a saved list of display names or complete answer histories.

What happens during a trivia question

While a question is active, Icon temporarily keeps track of which Discord user IDs have already answered it. This prevents repeated attempts on the same question, whether an answer was right or wrong. That temporary list is held in memory and is not written to the score file. Only correct answers increase stored point totals.

The bot uses Discord's Server Members Intent and member information to display current names alongside the top scores. The script does not enable the privileged Message Content Intent, scan ordinary chat messages or save channel conversations.

When information is visible

Leaderboard commands publish the top ten participants' names and point totals in the Discord channel. The bot also posts a public notice identifying whether a participant answered correctly or incorrectly; on incorrect answers, the correct option is shown privately to the participant. These Discord messages are subject to Discord's own retention and deletion practices.

Retention and security

All-time scores stay in scores.json until removed by the operator or the file is retired. The daily tally is replaced when the next correctly answered question occurs on a different date; it is not maintained as a permanent daily history by the supplied code. Leaving the server does not automatically remove an all-time score.

The JSON file is not encrypted by the bot itself. Its security depends on access controls and protection of the device where it is stored.

External services

Icon uses Discord for commands, interactions and leaderboards. Trivia questions come from a local question file (trivia.json). The supplied code does not transmit player scores to an external trivia provider or advertising service.

02 / Your choices

Your trivia record.

You can view published rankings with /scores. Your score is associated with your Discord account ID so the bot can recognise correct answers over time.

Access, correction and deletion

To ask what Icon has stored about you, request a correction or have your scores removed, contact:

blackpeach-privacy@proton.me

Include your Discord user ID so we can identify the correct score entry. The operator handles these requests manually; the current version has no self-service data deletion command. Removing a score entry does not automatically delete leaderboard messages already posted in Discord.

Third-party privacy information

Scope: This policy covers the Icon trivia bot's Discord interactions and local score file. The bot does not collect payments, account passwords or Discord message histories.
