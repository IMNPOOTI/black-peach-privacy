Tomoka

STARDOM · wrestling predictions

STARDOM event predictions, private picks, public competition standings and optional event notifications.

Privacy policy · 9 October 2026

01 / Privacy policy · effective 9 October 2026

Predictions, not conversations.

Tomoka lets members make predictions about STARDOM wrestling events, review their picks, compare scores and opt into event notifications. The bot uses Discord account identifiers to connect each person's selections to their predictions.

Information collected and stored

  • Discord user ID: identifies which participant submitted each prediction.
  • Prediction details: the relevant event ID, match number, question identifier and order, and the answer selected for that question (such as a winner or match result).
  • Competition scores: current-event and all-time totals are calculated from stored predictions and matching results when the leaderboard is requested.

Selections are saved in a local SQLite database (predictions.db) operated by the bot owner. The supplied code also reads local event information (event.json) and wrestler power-ranking data (ratings.json); those files contain wrestling content rather than a collected Discord chat history. The leaderboard references a results database table, but management of that table is not shown in this file.

Discord interactions and notifications

The /predict and /picks commands display your questions and saved selections privately to you using Discord's ephemeral responses. The bot checks who is interacting with a prediction menu so another person cannot submit answers on your behalf.

Tomoka can read your current server roles for its /notifications command and can add or remove the designated notification role when you request it. That preference is reflected in Discord's server role membership; the supplied code does not create a separate database of notification subscribers.

The script uses Discord's default intents and does not request the privileged Message Content Intent or archive ordinary channel messages.

When information is visible

Leaderboard commands display participant names and scores in a Discord channel. To show a current name, the bot may request the member's display name from Discord using a stored user ID. An administrator can also announce new prediction events and mention the opted-in notification role. Your individual /picks response is private; public leaderboard posts and announcements follow Discord's own retention rules.

Retention and security

Prediction records are kept in predictions.db across events; this version of the bot does not automatically expire them or erase them when someone leaves the server. They remain until removed by the operator or the database is retired. The bot code does not add database encryption, so protection relies on the host computer's security measures.

External services

Tomoka uses Discord to receive selections, manage the notification role and publish results. It reads its event and wrestler data from locally supplied files. The supplied script does not send participants' predictions to a separate wrestling website, analytics provider or advertising service.

02 / Your choices

Your prediction record.

Use /picks to view your saved selections for the active event and /leaderboard to see competition standings. Use /notifications to enable or disable the optional Discord notification role.

Access, correction and deletion

To request access to your prediction records, correct an account association or ask for your saved predictions to be removed, contact:

blackpeach-privacy@proton.me

Include your Discord user ID so we can identify your records. Requests are handled by the operator; the current script has no self-service deletion command. Deleting stored predictions may change historical leaderboard totals and does not remove messages already published by Discord.

Other privacy information

Scope: This policy covers Tomoka's Discord interactions and prediction records. It does not cover separate tools that may prepare the local wrestling event files.
