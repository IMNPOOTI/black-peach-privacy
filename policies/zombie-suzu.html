Zombie Suzu

Private testing / experimental

An operator-only development bot used to test features before they move to other applications.

Privacy policy · 9 October 2026

01 / Privacy policy · effective 9 October 2026

A restricted testing application.

Zombie Suzu is a private development and testing application for The Black Peach. It has no general-purpose community features. Access is restricted to the operator's private testing channel; regular server members cannot interact with it through public bot commands.

Current data practices

  • No public service: Zombie Suzu is not used to run games, leaderboards, authentication or other standing services for members.
  • Controlled tests: when the operator tests a feature, it may temporarily process Discord interactions and any test inputs deliberately submitted in the restricted channel.
  • No ongoing member dataset: the application is not intended to collect ordinary members' messages, create member profiles or maintain a permanent community dataset.

Based on the operator's description, Zombie Suzu currently has no active production feature or standing personal-data database. Because the application is used for occasional development experiments, temporary test data or technical logs may exist while a specific test is running; those practices depend on the test and are not claimed to be identical for every possible future experiment.

How tests are handled

Experimental functionality is developed in the restricted test environment. When a feature is ready for community use, its code is moved into another dedicated application rather than deploying Zombie Suzu as a public bot. The receiving application's privacy policy is reviewed and updated if the new feature changes its data handling.

Retention and third-party services

There is no standing retention period for a permanent user database because none has been identified for this testing application. Temporary local test information is intended to be cleared when it is no longer necessary. Messages sent in the private testing channel remain subject to Discord's own storage and deletion practices.

Zombie Suzu operates through Discord. No separate routine third-party user-data integration has been identified for the currently described, otherwise empty testing application. A future experiment using another service will require the relevant privacy description to be updated before broader use.

02 / Your choices

Testing only.

Zombie Suzu is not presently offered as an interactive bot to the wider community. You do not need to join a test or provide it with information to participate in The Black Peach.

Access and deletion requests

If you believe this application processed information about you, or wish to request access, correction or deletion, contact:

blackpeach-privacy@proton.me

Include your Discord user ID and, if relevant, the testing interaction concerned. The operator will review any applicable test data and handle the request manually. Messages already stored by Discord may need to be addressed separately.
