Lady C

Chess puzzles and profiles

Chess puzzles, personal ratings and standings, including blind puzzles and Human Tower challenges.

Privacy policy · 9 October 2026

01 / Privacy policy · effective 9 October 2026

Chess statistics, not chat archives.

Lady C provides chess puzzles, ratings, leaderboards and optional lookups of public chess profiles. Its permanent player database is focused on puzzle progress and statistics, rather than conversations.

Information collected and stored

  • Discord user ID: the identifier used to retrieve and update each player's statistics. The local database stores the ID, not a permanent copy of the player's Discord display name or avatar.
  • Normal and blind-puzzle performance: current and peak ELO, streaks, completed puzzles, successful and failed attempts, and hints used.
  • Human Tower and Blind Tower progress: run counts, highest floor cleared, total floors cleared and the current checkpoint.

These records are saved in a local SQLite database (lady_c.db). A player record may be created when a chess command needs it, including when another member requests that person's /profile.

Message content and interactions

Lady C has Discord's Message Content Intent enabled for a specific feature: it checks incoming non-bot messages against a locally configured set of thank-you phrases and may post a preset media response. The code does not save those message texts, build a conversation database or use them to train a model.

Puzzle selections, moves, hints and unfinished puzzle state are handled in memory during an active session. Inactive sessions time out after approximately 20 minutes. Rated outcomes and Tower progress are recorded as statistics; the bot does not save a full personal move-by-move puzzle history in its player table.

What other members can see

When requested, Lady C shows puzzle standings and user profiles in Discord. To label those results it can retrieve Discord display names and avatars. Standings names are reused from an in-memory cache for approximately one hour; stale entries may remain in memory until replaced or the bot restarts. This cache is not part of the permanent player database.

Chess websites and public profiles

Lady C uses a local Lichess puzzle dataset and may request public source-game PGN data from Lichess to prepare blind puzzles. The optional /online-profile command sends the chess-site username supplied in the command to Lichess or Chess.com to retrieve public account information. This public profile information may include ratings, activity, a biography, location or other details the chess-site account has made public, which Lady C then displays in Discord. The bot does not write those external profiles to its player database.

Retention and protection

The current code does not automatically delete ratings or statistics when a user leaves the server or becomes inactive. Player data remains locally until removed by the operator or the database is retired. The script has no scheduled personal-data backup routine and no application-level database encryption; storage protection relies on the machine's access controls.

02 / Your choices

Your chess information.

You can view your recorded statistics with /profile, and the published leaderboard with /standings. The optional external profile lookup only runs when someone supplies a chess-site username.

Access, correction and deletion

To request access to your record, correct an account association, or ask for your puzzle statistics to be removed, contact:

blackpeach-privacy@proton.me

Include your Discord user ID so we can locate your record. Requests are handled by the operator; the current bot has no built-in self-service deletion command. Removing the local record does not automatically delete messages previously posted to Discord.

Third-party policies

  • Lichess Privacy Policy
  • Chess.com Privacy Policy
Scope: This policy covers Lady C's Discord interactions, locally stored player statistics and optional public chess-site lookups. It does not cover data held independently in members' Lichess or Chess.com accounts.
